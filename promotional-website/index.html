APK Installation Guide

How to side-load and set up the CDM Library app on your Android device.

Click the Download App APK button in the hero section or the header. The download of the file (typically named cdm-library-app.apk) will start automatically in your browser.

Because this app is distributed directly for campus use rather than the Google Play Store, you need to grant permission to install it:

  1. Open your device Settings.
  2. Navigate to Security or Privacy settings.
  3. Look for Install Unknown Apps or Special App Access.
  4. Select the browser you used to download (e.g. Chrome) and toggle on Allow from this source.

Locate the downloaded file using your notification bar or a File Manager app under the Downloads folder. Tap the APK file and select Install. Once completed, tap Open to launch the application.
